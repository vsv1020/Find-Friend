## 七、开发命令

```bash
npm test              # 136 项单元测试
npm run sync:config   # 部署前必须执行:同步 rules 与 common 到各云函数
node scripts/init-db.js   # 打印建库指令
```

> ⚠️ **每次部署前都要跑 `sync:config`。** 云函数是独立 node 模块,读不到目录外的文件,
> 领域逻辑靠这个脚本复制进去。忘了跑,线上跑的就是旧规则。
