# 10 · 界面设计方向:「有温度的出门感」

> 2026-10-02 定稿。用户原话是「要有 date 的氛围,约会的氛围」;与 PRD §5「只匹配活动、不匹配人」正面冲突,经确认改为本方向。

## 一、为什么不是「约会感」

PRD §5 的反约会设计不是道德洁癖,是**留存策略**:一旦界面暗示「这里能遇到人」,用户会按约会软件的方式使用它 —— 看人、挑人、失望、流失。
我们卖的是「周末有个地方可去、去了有人一起」。**期待感来自出门,不来自对面坐着谁。**

所以界面上**永远没有**:头像、昵称列表、性别可见、「谁也报了」、心形、粉色、配对动效。
能看到的只有:什么局、什么时候、在哪、**还差几个人**。

## 二、设计令牌(`miniprogram/app.wxss`)

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F7F2EA` | 页面底,暖纸 |
| `--card` | `#FFFDF9` | 卡片,比纯白暖一度 |
| `--ink` / `--ink-2` / `--mute` | `#26221D` / `#5C554B` / `#9A9084` | 三级文字 |
| `--amber` / `--amber-soft` | `#D98A3C` / `#FBEEDD` | 傍晚琥珀:**唯一**的行动色,用在「还差 N 人」 |
| `--olive` / `--olive-soft` | `#6F7D5C` / `#EEF1E6` | 已成团 / 到位 |
| `--plum-soft` / `--sage-soft` / `--amber-soft` | | 酒馆 / 展览 / 咖啡 三种局的卡片底色渐变(`.tint-bar/.tint-art/.tint-coffee`) |

所有页面只引用令牌,不写裸色值。海报 canvas(`utils/poster.js`)用同一组值。

## 三、几个关键决定

1. **座位点替代数字**。`.seats` 画 N 个圆点,实心是已报名、空心是空位;到达成团线后整体变橄榄绿。它比「2/6」更直觉,也更诚实 —— 只是计数,不对应任何人。`utils/format.js#seatDots`。
2. **「还差 1 人」从红字变暖标签**。它是全产品最重要的一句话,但不该像告警。琥珀底 + 圆角 = 「来呀,就差你」。
3. **时间当主角**。列表卡左侧大号 `15:00`,详情页 64rpx 时钟。出门这件事最重要的信息是「几点」。
4. **局主的一句话当引言**。详情页用左侧琥珀竖线把 description 作为引语呈现 —— 这是这个局唯一的「人味」,且不暴露局主身份。
5. **首页问候**:「这周末,出门吧 / 点一下,就有人一起。」—— 把周末变成一件值得期待的事,不提「遇见」。
6. **报名成功**:「约好了」+ 橄榄绿对勾。候补态是「先排着,有位子就叫你」。
7. **发局表单、后台、局主工具**:沿用令牌,不做额外装饰 —— 这些是工具页。
